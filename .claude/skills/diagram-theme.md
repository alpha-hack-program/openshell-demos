# SVG Diagram Theme Reference

This document defines the design system for all SVG diagrams generated by the
`diagram` skill. It is derived from the existing diagrams in `docs/diagrams/`.

## Font

```
font-family="Inter, -apple-system, BlinkMacSystemFont, sans-serif"
```

### Phase header accents

Phase headers use a tinted row. Pick the semantic color that matches the
phase's actor. Example for indigo:

```
fill="#eef2ff"   stroke="#c7d2fe"  text="#3730a3"   (light)
fill="#1e1b4b"   stroke="#312e81"  text="#a5b4fc"   (dark)
```

## Arrow markers

```xml
<marker id="arrow-{name}" viewBox="0 0 10 7" refX="10" refY="3.5"
        markerWidth="10" markerHeight="7" orient="auto-start-reverse">
  <polygon points="0 0, 10 3.5, 0 7" class="arrow-{name}"/>
</marker>
```

Where `{name}` is the semantic color (blue, green, etc.) and the polygon fill
matches `stroke` from that color row. The class-based approach allows dark
mode to override the fill via CSS.

## Sizes

| Element            | Value            |
|--------------------|------------------|
| Corner radius      | 12 (outer), 8 (container), 6 (card), 4 (label), 18 (pill/actor) |
| Stroke width       | 1.5 (arrows, borders), 1 (lifelines, subtle) |
| Dash pattern       | `4,4` (lifelines), `6,3` (alt-box), `5,3` (return arrows) |
| Title font-size    | 18               |
| Actor font-size    | 13               |
| Step font-size     | 11               |
| Caption font-size  | 10               |
| Detail font-size   | 9                |

## CSS structure for dual-mode support

Embed this `<style>` block inside the `<svg>` element to enable automatic
light/dark switching:

```xml
<style>
  /* Light mode (default) */
  .bg        { fill: #f8fafc }
  .surface   { fill: #f1f5f9 }
  .card      { fill: #ffffff }
  /* ... all tokens ... */

  @media (prefers-color-scheme: dark) {
    .bg        { fill: #0f172a }
    .surface   { fill: #1e293b }
    .card      { fill: #1e293b }
    /* ... all dark overrides ... */
  }
</style>
```

Use CSS classes on SVG elements instead of inline `fill`/`stroke` attributes
so the media query can override them.
