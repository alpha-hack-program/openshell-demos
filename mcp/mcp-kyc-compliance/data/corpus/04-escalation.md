# Escalation to compliance

Any transaction that does not clearly fit the client's usual activity
profile must be documented and escalated for review before execution —
even if the transaction does not exceed any automatic monetary threshold
on its own. Thresholds catch large, obviously unusual transactions;
escalation exists to catch the smaller but still-anomalous ones that a
threshold alone would miss, such as an unfamiliar counterparty, an
unexplained change in transaction pattern, or activity inconsistent with
the client's declared sector of interest.

Escalation means recording what made the transaction unusual and routing
it to a compliance officer for review before it proceeds, not after. A
transaction that was allowed to execute before escalation defeats the
purpose of the control.
